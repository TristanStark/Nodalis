# Nodalis.Benchmarks\n\nBenchmark local sans dépendance tierce pour les gros workspaces Nodalis.\n\nExemple :\n\n    dotnet run --project benchmarks/Nodalis.Benchmarks/Nodalis.Benchmarks.csproj -c Release -- --documents 5000\n\nLa sortie JSON contient les durées ainsi que les compteurs de documents hashés, parsés, réutilisés et invalidés. Voir docs/performance-budgets.md pour les budgets et leur interprétation.\n
