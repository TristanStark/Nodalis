# Glossaire — Application Nodalis

## Relation typée

**Définition :** lien explicite entre deux documents identifié par le GUID de la cible ; son type définit la sémantique d'impact.

**Liens :** [[Spécification des liens]]

## Document composite

**Définition :** fichier Markdown contenant une inclusion virtuelle `![[GUID#Section]]` sans copie de contenu.

**Liens :** [[Documents composites 1.6]]

## Vue dynamique

**Définition :** projection en lecture seule sur les données métier canoniques du workspace.

**Liens :** [[Vues dynamiques 1.5]]
