# Notes rapides — Refonte explorateur 122

Le projet Ultra-simple sert ici d'exemple à l'usage des interventions plutôt qu'à une conduite de projet complète. La demande réelle #122 concernait l'ergonomie du worktree.

- Les en-têtes de projet doivent rester visibles pendant le défilement.
- Les boutons à côté d'« Explorateur » ne doivent pas être rognés.
- Le contraste et l'indentation doivent rendre les projets lisibles.

Voir [[Fiche de Maintenance]] et [issue GitHub #122](https://github.com/TristanStark/Nodalis/issues/122).
