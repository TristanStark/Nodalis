# Documents composites 1.6

## Syntaxe

Une inclusion sur une ligne dédiée récupère une source ou une section par GUID :

`![[bb000000-0000-4000-8000-000000000008#Résultats attendus]]`

Le contenu reste dans le document source ; le rapport reconstruit son aperçu sans altérer les fichiers d'origine.

## Démonstration

Ouvrir [[Rapport de qualification 1.x]] : ce document inclut des sections de [[Plan de recette]], [[Architecture des évolutions]] et [[Décision - Markdown canonique]].

## Exports

Markdown avec marqueurs, Markdown résolu, HTML autonome ou DOCX local ; le résultat est un instantané distinct des sources.
